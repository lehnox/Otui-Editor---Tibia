O Otui Editor - PRO é um sistema para a criação e edição de interfaces de usuário (UI) de forma visual e intuitiva, com foco em arquivos .otui de projetos do Otclient. Ele oferece uma interface WYSIWYG (What You See Is What You Get), permitindo aos desenvolvedores arrastar, redimensionar e editar elementos de UI diretamente na tela.


## Contém:


- Edição Visual: Manipule widgets como janelas, rótulos e botões diretamente no canvas.

- Parser Avançado: Leitura e interpretação de todos os atributos, estados e eventos de arquivos .otui, incluindo imagens e hierarquia.

- Painel de Propriedades Interativo: Edite as propriedades do widget selecionado em tempo real, com a exibição das alterações no canvas.

- Exportação Fiel: Exporte seu projeto para um arquivo .otui completo, com suporte a imagens e hierarquia.

- Carregamento Inteligente: O sistema resolve a localização de imagens em várias pastas, incluindo a pasta data do cliente, para evitar erros de arquivo não encontrado.

- Histórico de Edições: Funcionalidades de Desfazer e Refazer para maior segurança no processo de edição.


## Instalação

Clone o repositório

```bash
 git clone [https://github.com/lehnox/otui-editor.git](https://github.com/lehnox/otui-editor.git)
```
Instale as dependências:
O projeto utiliza a biblioteca PySide6. Instale-a com pip:

  ```bash
 pip install PySide6
```
Execute o Editor:

  ```bash
 python Otui.py
```
